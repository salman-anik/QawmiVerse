    How to find a madrasa

    1. Type a madrasa name or place in the search box above.
    2. Narrow down with Division → District → Thana/Upazila.
    3. Use the marhala filter to see madrasas listed for a specific marhala.
    4. Open a madrasa page for the address and a Google Maps link.

    Frequently asked questions

    Where does this list come from?

    From the 2019 result-related madrasa list of Wifaqul Madarisil Arabia Bangladesh. If a madrasa appears under several marhalas it is shown once with all its marhalas listed.

    What is a marhala?

    A marhala is a level or stage in the Qawmi education system. Each madrasa shows which marhalas are listed for it.

    Is the data up to date?

    The list is from 2019. Newer madrasas may be missing and addresses may have changed, so please verify before visiting.

    How to find a madrasa

    1. Type a madrasa name or place in the search box above.
    2. Narrow down with Division → District → Thana/Upazila.
    3. Search by Wifaq ilhak number, for example 5/1036.
    4. Use the type filter to show men’s/general or women’s madrasas.
    5. Open a madrasa page for the address and a Google Maps link.

    Frequently asked questions

    Where does this list come from?

    It combines the 2019 Wifaq result list with the user-provided list of women’s madrasas in Dhaka District.

    What is an ilhak number?

    An ilhak number is a Wifaq identifier for a madrasa. Enter the number in the search box to find a listing.

    Is the data up to date?

    The list is from 2019. Newer madrasas may be missing and addresses may have changed, so please verify before visiting.
